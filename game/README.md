# نور المعرفة — Noor al-Ma'rifa

لعبة مطابقة ثلاثية (Match-3) تعليمية على نهج أهل البيت (ع)، باللغة العربية، يتعلّم فيها اللاعب عن القرآن والسيرة والمعصومين (ع) والعقيدة والأحكام والأدعية والتاريخ والمشاهد المشرّفة.

An Arabic, Shia-themed educational match-3 game. Knowledge replaces in-app purchases: every move, booster, and continue is earned by answering questions.

## التشغيل

بدون أي تثبيت: افتح `index.html` في المتصفح، أو شغّل خادماً محلياً:

```bash
cd game
python3 -m http.server 8000
# ثم افتح http://localhost:8000 على الهاتف أو الحاسوب
```

## تطبيق أندرويد (APK)

يُبنى ملف APK تلقائياً على خوادم GitHub عند كل تعديل في `game/` أو `android/` (ملف `.github/workflows/android-apk.yml`)، ويُنشر في صفحة **Releases** للمستودع باسم `apk-latest`:

1. افتح صفحة Releases في المستودع من هاتفك ونزّل `noor-almarifa.apk`.
2. افتح الملف واسمح بالتثبيت من هذا المصدر عند السؤال.

مشروع أندرويد في مجلد `android/`: تطبيق WebView خفيف بدون مكتبات إضافية، يعمل **دون إنترنت** (لا يطلب إذن الإنترنت)، والخطوط مضمّنة في `game/fonts/`. للبناء محلياً عبر Android Studio أو: `cd android && ./gradlew assembleRelease`.

**التوقيع:** النسخ التجريبية موقّعة بمفتاح اختبار مرفق (`android/app/noor-test.keystore`) حتى تُثبَّت التحديثات فوق النسخة السابقة دون فقدان التقدم. **قبل النشر في Google Play** أنشئ مفتاحك الخاص وأضفه في أسرار المستودع: `NOOR_KEYSTORE_BASE64` و`NOOR_KEYSTORE_PASSWORD` و`NOOR_KEY_ALIAS` و`NOOR_KEY_PASSWORD`، وغيّر معرّف التطبيق `com.noormarifa.game` في `android/app/build.gradle` إذا أردت.

## فكرة اللعبة

| العنصر | الوصف |
|---|---|
| **اللوحة** | اسحب القطع الملوّنة المبتسمة (نجمة، تمرة، رمّانة، عنب، زيتونة، قطرة ماء) لتكوين ٣ أو أكثر. لا تُستخدم الرموز المقدّسة (كالمصحف) قطعاً تُفرقَع |
| **القطع الخاصة** | ٤ في خط = سهم يمسح صفاً/عموداً · شكل L/T = انفجار · ٥ في خط = «نور» يمسح لوناً كاملاً. ودمج قطعتين خاصتين يعطي تأثيراً أقوى |
| **قطعة المعرفة ؟** | تظهر عشوائياً؛ عند مسحها يُطرح سؤال، والإجابة الصحيحة تمنح شعاع نور يمسح صفاً + حركة إضافية |
| **الأهداف** | جمع عدد من قطع معيّنة و/أو فرقعة الفقاعات |
| **نوري** | حمامة لطيفة ترشد الطفل: ترحّب به، تعطيه النصائح، وتفرح معه أو تشجّعه |
| **الصحن** | النجوم المكتسبة من المستويات تُصرف في ترميم صحن المقام (بلاط، نافورة، حديقة، فوانيس، كاشي، إيوان، مئذنتان، قبّة ذهبية) |

### اقتصاد المعرفة (بدلاً من الشراء من Google Play / App Store)

لا توجد أي مشتريات داخل اللعبة. العملة الوحيدة هي **نقاط المعرفة**، وتُكسب فقط بالإجابة عن الأسئلة:

- عندما يصعب المستوى أو تنفد الحركات، يذهب اللاعب إلى **بنك الأسئلة**، ويختار القسم ومستوى الصعوبة، ثم يجيب ويكسب النقاط، ويعود إلى المستوى نفسه من حيث توقف.
- **الكسب:** سهل +١ · متوسط +٢ · صعب +٣ · كل ٣ إجابات صحيحة متتالية = +١ مكافأة · سؤال اليوم = +٢ مكافأة.
- **الإنفاق:** +٥ حركات = ٥ · المطرقة = ٣ · السهم = ٤ · الخلط = ٢.
- **منع التحايل:** السؤال الذي سبق حلّه يمنح نقطة واحدة فقط، والإجابة الخاطئة تكسر السلسلة (التخمين العشوائي لا يفيد)، والأسئلة الخاطئة تعود لاحقاً في «مراجعة أخطائي» حتى يتقنها اللاعب.

الأسعار قابلة للتعديل في `js/util.js` (`N.COSTS` و `N.POINTS_BY_DIFFICULTY`).

## إضافة الأسئلة (للوصول إلى ٥٠٠٠+ سؤال)

1. افتح `data/questions.csv` في Excel أو Google Sheets (الترميز UTF-8).
2. أضف صفاً لكل سؤال. ضع الإجابة الصحيحة دائماً في عمود `correct` والخيارات الخاطئة في `wrong1..3`، واللعبة تخلط ترتيبها تلقائياً.
3. اترك `id` فارغاً ليُولَّد تلقائياً، واجعل `status` = `draft`.
4. بعد مراجعة العالِم: غيّر `status` إلى `approved` (أو `rejected` لإخفائه) واكتب اسمه في `reviewer`.
5. ولّد ملف اللعبة وافحصه:

```bash
node tools/questions-csv.js import data/questions.csv
node tools/validate-questions.js
```

**الأقسام المتاحة:** `quran` القرآن · `prophet` السيرة · `masumeen` المعصومون (ع) · `aqeedah` أصول الدين · `fiqh` الأحكام · `akhlaq` الأخلاق والحديث · `duas` الأدعية والزيارات · `history` التاريخ · `places` المشاهد · `occasions` المناسبات.

**الصعوبة:** `1` سهل · `2` متوسط · `3` صعب.

> ⚠️ الأسئلة الحالية (١٦٨ سؤالاً) **مسودة** كتبتها أداة ذكاء اصطناعي، وتحتاج إلى مراجعة عالم دين أو طالب حوزة مؤهّل قبل النشر. أسئلة الأحكام مقتصرة على المسائل المتفق عليها بين المراجع؛ ويُقترح لاحقاً إضافة خيار «اختيار المرجع» للمسائل الخلافية.

## ضوابط المحتوى

- لا تُصوَّر وجوه النبي ﷺ ولا الأئمة (ع) ولا أهل البيت (ع) إطلاقاً؛ الرسومات زخارف وعمارة فقط.
- لا موسيقى؛ مؤثرات صوتية خفيفة فقط، ويمكن إيقافها من الإعدادات.
- يُراعى الطابع الحزين لمناسبات محرّم وصفر (مقترح: وضع لوني هادئ خلال تلك الأيام).

## الخطوات القادمة المقترحة

- توسيع البنك إلى ٥٠٠٠+ سؤال مع سير عمل المراجعة أعلاه.
- خادم سحابي (Firebase أو Supabase) لتحديث الأسئلة دون تحديث التطبيق.
- تغليف اللعبة كتطبيق Android/iOS عبر Capacitor.
- لغات إضافية (الفارسية، الأردية، الإنجليزية)، ومستويات وفصول جديدة، ومراحل ترميم بعد الصحن (المكتبة، الحسينية).
